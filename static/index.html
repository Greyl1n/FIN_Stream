Dual-Engine Architecture

TMDB API + Direct-Link Engine

StreamPulse is currently active with live streaming catalogs & direct launch links. Add your free TMDB API Key (or Read Access Token) to unlock official TMDB discovery, YouTube trailers, and hybrid metadata enrichment.

How to get a free TMDB API key in 60 seconds:

  1. Create a free account at themoviedb.org/signup.
  2. Open your TMDB API Settings page.
  3. Click Create → Developer, fill in "Personal Streaming App", and copy your API Key (or API Read Access Token).
  4. Paste it above and click Verify & Save — it will be saved to your local .env file automatically.
